## Primary implemented gameplay promise

A placeable minecart-sized Rail Beetle surveys cave-floor rail extensions, proposes bounded routes, consumes its own rails/supports/fuel to lay track, and can be controlled via its menu/route selection (including beacon-targeted routes). It supports Create minecart coupling when installed, with a discoverable cave siding and a recoverable body. Sources: `RailBeetleItem.useOn`, `RailBeetleEntity`, `TerrainRoutePlanner`, `RailBeetleMenu`, `RailBeetleNetwork`, `SidingMarker` and `SidingWorldgen`. This is source implementation, **not** proof that each interaction works in the staged modpack. Optional power providers, upgrade families and visual polish are not prerequisites to establishing this core promise.

- `SidingWorldgen`, `SidingFeature`, `RailCamp`, `SidingPiece` and `SidingMarker` describe natural cave-side discovery. Marker initializes one Beetle, one minecart and one chest cart with persistent one-shot state; Beetle starts with 64 rails, 64 cobblestone and 16 coal, chest cart separately with the same amounts. No recipe exists in this repository for the remote, frame, engines or modules: do not assume those are survival-craftable from these datapack resources; inspect the full pack's recipe providers separately.
